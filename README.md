# AI Agent 学习工作区

这是本次 AI Agent 线下课程共用的学习 repo。

它负责保存：

- 课前准备材料；
- 课堂任务和当前状态；
- 给 Agent 的指令；
- 学生学习记录；
- 多人和多 Agent 协作记录。

网页宠物代码不放在这里。网页宠物使用独立的 `ai-pet-demo` repo。

## 现在从哪里开始

### 还没上课

打开 [课前准备入口](pre-lite-workspace/START-HERE.md)。

### 已经进入课堂

打开 [课堂入口](course-workspace/README.md)。

### 你是 Agent

先读取 [Agent 入口](AGENT-START-HERE.md)。

## 学生电脑上的推荐位置

建议把这个 repo clone 到自己的 Obsidian Vault：

```text
My Obsidian Vault/
  Projects/
    AI Agent Learning Workspace/
```

课程结束后，这个 repo 仍然可以继续保存学习记录和后续项目入口。

## 重要边界

- 不在 repo 中保存密码、验证码、API Key 或付款信息。
- Agent 不代表人做最终决定。
- Agent 加入后先说明自己代表谁，再申请写入权限。
- 当前事实看 `course-workspace/CURRENT.md`。
- 当前任务看 `course-workspace/TASKS.md`。
- 重要选择看 `course-workspace/DECISIONS.md`。
- 网页宠物代码和 `.env.local` 留在独立代码 repo。
