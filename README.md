# AI Agent 学习 Workspace

这是两天 Agent 101 课程使用的公开学习 repo。它保存课程入口、给人看的教学材料、给 Codex 的提示词和演示说明。课程内容默认只读，不要求把个人作业写回这里。

网页宠物代码不放在这里，使用独立的 `ai-pet-demo` repo。

## 现在从哪里开始

- **第一次在 GitHub 打开本 repo**：打开 [公开 repo 入口](pre-lite-workspace/README.md)，让 Codex 把 repo 安装到 Obsidian；不需要等待邀请。
- **已经在 Obsidian 看到这个 repo**：继续打开 [安装后确认清单](pre-lite-workspace/materials/day-minus-1-preflight-checklist.md)，再在课前完成 Unit 0。
- **准备 Unit 0**：打开 [Unit 0：课前准备与验证](course-workspace/units/00-workspace-entry/STUDENT.md)。
- **想知道各 Unit 使用哪些 Skill**：打开 [课程 Skill 地图](SKILLS.md)。
- **老师开始线下课程**：打开 [课堂入口](course-workspace/README.md)，先验证 Unit 0，再进入 Unit 1。
- **你是第一次进入的 Codex**：先读取 [Codex 入口](AGENT-START-HERE.md)。

课前确认清单可以由老师直接发送，也可以从这个公开 repo 中打开。

## Unit 1 前确认三个公开 Repo

不需要老师发送 GitHub 邀请。进入 Unit 1 前，浏览器应能打开：

1. [AI Agent Learning Workspace](https://github.com/franksong2702/ai-agent-learning-workspace)：课程地图和提示词。
2. [AI Engineering Knowledge Base](https://github.com/franksong2702/AI-Engineering-KnowledgeBase)：课程引用的 AI 工程知识来源。
3. [AI Pet Demo](https://github.com/franksong2702/ai-pet-demo)：后续网页开发脚手架。

公开只代表可以阅读和 clone，不代表可以直接向老师的 repo 推送代码。Unit 4 默认使用 fork、个人 branch 和 Pull Request；不需要 collaborator 邀请。

## 电脑上的推荐位置

```text
~/Obsidian/
  Learn/
    Wiki/
    Agent 101/
  Projects/
    AI Agent Learning Workspace/  <- 本 repo

~/Projects/
  ai-pet-demo/                    <- 独立代码 repo
```

`Learn/Agent 101/` 放自己的课程笔记、反思、检查报告和 Skill 练习；本 repo 放只读课程材料和提示词。不要复制同一份材料到两处。

## 重要边界

- 不保存密码、验证码、API key、Cookie、Token 或付款信息。
- Codex 不代表人做最终决定。
- 课程 repo 默认只读。除非老师当场明确要求，不在这里创建作业或项目状态。
- 每次先读当前 Unit 的 `STUDENT.md`，再让 Codex 读同目录的 `AGENT-TASK.md`。
- 个人学习产物写入自己的 Obsidian `Learn/`；网页代码写入独立的 `ai-pet-demo` repo。
- 网页宠物代码和 `.env.local` 留在独立代码 repo。

当前仍未验证不同电脑 clone、Unit 0 准备、fork / Pull Request 或真实课堂结果。
