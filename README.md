# AI Agent 学习 Workspace

这是两天 Agent 101 课程共用的 private 学习 repo。它保存课程入口、课堂任务、给 Codex 的指令和需要共享的协作状态。

网页宠物代码不放在这里，使用独立的 `ai-pet-demo` repo。

## 现在从哪里开始

- **刚在 GitHub 接受邀请**：打开 [受邀后入口](pre-lite-workspace/README.md)，让 Codex 把 repo 安装到 Obsidian。
- **已经在 Obsidian 看到这个 repo**：继续打开 [安装后确认清单](pre-lite-workspace/materials/day-minus-1-preflight-checklist.md)。
- **老师已经明确说开始课堂**：打开 [课堂入口](course-workspace/README.md)，第一步是 Unit 0。
- **你是第一次进入的 Codex**：先读取 [Codex 入口](AGENT-START-HERE.md)。

邀请前使用的课前确认清单由老师单独发送，不需要在 private repo 里寻找。

## 电脑上的推荐位置

```text
~/Obsidian/
  Learn/
    Wiki/
    Agent 101/
  Projects/
    AI Agent Learning Workspace/  <- 本 repo

~/Projects/
  ai-pet-demo/                    <- 独立代码 repo
```

`Learn/Agent 101/` 放自己的课程笔记、反思和 Skill 练习；本 repo 放课程任务、提示词和共享协作状态。不要复制同一份材料到两处。

## 重要边界

- 不保存密码、验证码、API key、Cookie、Token 或付款信息。
- Codex 不代表人做最终决定。
- 新加入的 Codex 默认只能提交加入申请和自己的提案。
- 当前事实看 `course-workspace/CURRENT.md`。
- 当前任务看 `course-workspace/TASKS.md`。
- 重要选择看 `course-workspace/DECISIONS.md`。
- 网页宠物代码和 `.env.local` 留在独立代码 repo。

当前仍未验证真实邀请、不同账号 clone、三个 Codex 写回或真实课堂结果。
