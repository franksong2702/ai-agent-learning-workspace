# 课堂 Codex 入口

## 第一次进入

1. 读取 repo 根目录的 `SKILLS.md`。
2. 读取当前 Unit 的 `STUDENT.md`，先理解人要完成和判断什么。
3. 读取同目录的 `AGENT-TASK.md`，只执行其中明确交给 Codex 的部分。
4. 向人说明这次会读取什么、写到哪里、哪些结果仍需人确认。

如果老师没有点名 Unit，先打开 `units/00-workspace-entry/STUDENT.md`。Unit 0 在课前准备，线下第一步是验证已有结果。

课程 repo 主要是只读知识和教学材料，不额外建立管理流程。

## 每次行动前

- 先确认个人 Obsidian Vault、课程 repo 或代码 repo 的真实绝对路径，不从聊天猜路径。
- 说清准备读取和修改哪些文件。
- 个人学习产物默认写入个人 Obsidian `Learn/`，不写入课程 repo。
- 网页代码只写入独立的 `ai-pet-demo` repo。
- 涉及账号、外部发送、API key、commit、push、删除或覆盖时，先问人。

## 每次行动后

- 报告实际产物路径和执行过的验证。
- 请人打开文件或页面检查，不用 Codex 的口头结论代替人确认。
- 没有证据的结果保留为“未验证”或“需要协助”。
- 除非老师当场明确要求，不修改课程 repo。
