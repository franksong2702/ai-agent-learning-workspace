# Codex 加入 Workspace

## 给人看的说明

三个 Codex 一个一个加入：老师的 Codex 先确认 Workspace；随后第一个人的 Codex 和第二个人的 Codex 分别提交加入申请。

第一次加入只能创建自己的申请。老师确认它代表谁、能看到哪些文件、允许改哪些内容，并在申请的“老师确认”一节留下记录以后，才能更新共享状态。

## 给 Codex 的指令

把下面内容发给正在加入的 Codex，并只替换方括号内容：

```text
你正在加入 Agent 101 课程的共享学习 Workspace。

你代表：[老师 / 第一个人 / 第二个人]
你使用的工具：Codex

请先读取：
1. AGENT-START-HERE.md
2. course-workspace/AGENT-START-HERE.md
3. course-workspace/ROLES.md
4. course-workspace/CURRENT.md

先不要修改 CURRENT.md、TASKS.md 或 DECISIONS.md。

请根据 course-workspace/inbox/joins/TEMPLATE.md 创建一份加入申请：
- 老师的 Codex：course-workspace/inbox/joins/teacher-agent.md
- 第一个人的 Codex：course-workspace/inbox/joins/person-1-agent.md
- 第二个人的 Codex：course-workspace/inbox/joins/person-2-agent.md

加入申请要说明：
- 你代表谁
- 你能否读取 repo
- 你能否创建本地文件
- 你能否运行结构检查
- 你当前申请的权限范围
- 你需要老师确认什么

不要写入密码、Token、Cookie、API key、本机凭据路径或私人信息。
完成加入申请后停下来，等待老师确认。
```
