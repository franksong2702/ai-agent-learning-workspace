# AI Agent 101 课堂入口

这里是讲师、乐乐、宋乐涵和三个 Agent 共同使用的课堂 Workspace。

你不需要一次读完所有文件。课堂开始时只看：

1. [当前状态](CURRENT.md)
2. [当前任务](TASKS.md)
3. [角色和权限](ROLES.md)

如果你的 Agent 第一次进入，先打开 [Agent 加入说明](JOIN.md)。

## 课堂中怎么用

- 现在发生什么：看 `CURRENT.md`。
- 接下来做什么：看 `TASKS.md`。
- 为什么这样决定：看 `DECISIONS.md`。
- 课程产物：放在 `outputs/`。
- 过程证据和截图：放在 `artifacts/`。
- 暂时不确定的材料：放在 `inbox/`。

每次重要进展都要落到文件，但不要把聊天逐字记录下来。
