# AI Agent 101 课堂入口

这里是老师、两位学习者和三个 Codex 共同使用的课堂 Workspace。

你不需要一次读完所有文件。老师明确说“开始课堂”后，按这个顺序：

1. [当前状态](CURRENT.md)
2. [Unit 0：进入共享学习 Workspace](units/00-workspace-entry/STUDENT.md)
3. [角色和权限](ROLES.md)

如果你的 Codex 第一次进入，先打开 [Codex 加入说明](JOIN.md)。

Unit 0 完成后，从 [Unit 0-5 课程入口](units/README.md) 进入后续单元。不要跳过当前 Unit 的前置和人工检查。

## 课堂中怎么用

- 现在发生什么：看 `CURRENT.md`。
- 课程准备与课堂进度：看 `TASKS.md`。
- 为什么这样决定：看 `DECISIONS.md`。
- 课堂要求共享和检查的提交：放在 `outputs/`。
- 过程证据和截图：放在 `artifacts/`。
- 暂时不确定的材料：放在 `inbox/`。

自己的完整课程笔记、反思和学习卡留在个人 Obsidian `Learn/` 中。共享 Workspace 只记录需要协作或检查的内容，不把聊天逐字记录下来。
