# Unit 0

## 先把工作台准备好

今天结束时，课程材料能打开，个人文件有地方保存，Codex 能在 Obsidian 中完成一次真实读写。

---

# Unit 0 只解决一件事

课前已经准备了 Codex、GitHub 和 Obsidian。

离开 Unit 0 前，四件事必须有真实结果：

```text
课程材料看得见
个人路径找得到
Codex 可以读写文件
出问题时知道怎样继续
```

今天的测试文件只是检查结果，不是正式学习产物。

---

# 四个工具各有一份工作

| 工具 | 在这门课里负责什么 |
| --- | --- |
| GitHub | 提供课程材料和代码项目 |
| Obsidian | 阅读、编辑和保存自己的 Markdown 文件 |
| Codex | 读取文件、使用工具、执行任务 |
| Claudian | 在 Obsidian 中与 Codex 交互 |

它们不是四套知识库，而是同一个工作台的不同部分。

---

# 三类内容不要混在一起

```text
课程材料
Obsidian/Projects/AI Agent Learning Workspace/
只读

个人学习记录
Obsidian/Learn/Agent 101/
由自己和 Codex 共同整理

代码项目
电脑上的独立代码 Repo
后面的开发单元使用
```

API key、密码和验证码不写进任何 Markdown。

---

# Codex 要先知道读哪里、写哪里

今天只验证一条最小路径：

```text
读取课程 repo 中的 Unit 0 页面
                ↓
在个人 Learn/Agent 101/Unit 0/ 中写检查文件
                ↓
人亲自打开文件确认
```

课程 repo 不保存个人报告，也不需要提交作业。

---

# 动手 1：找到自己的工作台

打开 [Unit 0 实验页](STUDENT.md)。

先自己找到：

1. 课程 repo；
2. 个人 `Learn/Agent 101/`；
3. 电脑上的代码项目位置。

再让 Codex 核对实际路径、GitHub remote 和三个公开 repo。

完成后，在 Obsidian 中打开 `SETUP-REPORT.md`。

---

# 两个 Skill 今天只做准备

Unit 0 准备：

- `teach`：遇到真正不懂的概念时，帮助理解和复述；
- `aihot`：后面寻找真实 AI 资料时使用。

今天只确认三件事：

```text
来源正确
新 Codex task 能读取
最小验证有真实结果
```

怎样拆解和编写 Skill，放到后面的专门单元。

---

# 动手 2：验证 Skill 已经可用

回到 [Unit 0 实验页](STUDENT.md)：

1. 让 Codex 按课程提供的固定来源检查两个 Skill；
2. 如果刚安装，重新开一个 Codex task；
3. 确认新 task 能读取 `teach` 和 `aihot`；
4. 用 `aihot` 做一次最小查询。

这一步是在检查工具，不展开学习新闻内容。

---

# Claudian 把 Codex 带进 Obsidian

```text
人
↓ 阅读、选择、检查
Obsidian
↓ 提供 Markdown Workspace
Claudian
↓ 在 Obsidian 中连接
Codex
↓ 读取和写入
个人 Vault 文件
```

Claudian 不是新的模型，也不是第二个知识库。

---

# 动手 3：完成最小读写检查

请亲自在 Obsidian 界面完成前三步：

1. 在 Obsidian 中安装并启用 Claudian；
2. 在界面中选择 Codex；
3. 让它读取 Unit 0 页面；
4. 只在个人学习区写入 `CLAUDIAN-CHECK.md`；
5. 人亲自打开并确认内容和路径。

安装、启用和 provider 都由人看界面确认。

---

# 出问题，不等于课程停下

如果 Claudian 没有完成检查：

```text
保留准确错误
记录插件和 Codex 的可见状态
直接使用 Codex 操作同一个 Vault
继续后面的课程
```

没有验证的结果不写成成功，但也不让一个插件阻断整门课。

---

# 离开 Unit 0 前，亲自确认

- 我能在 Obsidian 中打开课程 repo。
- 我知道个人学习记录写在哪里。
- 我知道代码项目不放在课程笔记目录里。
- 新 Codex task 能读取两个已准备的 Skill。
- Claudian 完成最小读写，或者留下了准确错误和降级路径。
- 课程 repo 没有出现个人报告或密钥。

这些都来自实际文件和界面，不来自口头猜测。

---
