# Codex Task：Unit 2 文章编译、学习卡与 Pitch

## 目标

帮助人把一篇有来源的 Raw 文章编译成可检查的个人知识文件。不要替人完成理解和判断，也不要把个人学习卡写入课程 repo。

## 前置

开始写文件前，逐项确认：

1. 个人 Obsidian 知识库的绝对路径。新建知识库默认可在 `~/Obsidian/`，已有长期知识库沿用现有路径。
2. 主题名称，以及唯一写入目录 `<个人 Obsidian 知识库>/Learn/Wiki/<主题>/`。
3. 原文链接和 Raw 文件路径；若文件不存在或来源无法打开，先停下报告。
4. `materials/WEB-CLIPPER-SETUP.md` 的测试抓取是否已经由人检查；未完成时先协助准备，不进入编译。
5. Pitch 面向谁，以及希望重点讲清什么。
6. 课程 repo 保持只读，所有个人产物只写入第 2 项确认的目录。

## 允许动作

- 读取本 Unit、三个模板、原文链接和 Raw 文件。
- 读取 Web Clipper 准备页，解释模板字段并检查实际抓取文件；浏览器扩展安装、权限确认和 Vault 选择由人操作。
- 在唯一写入目录中创建缺失的主题目录和 `raw/` 子目录。
- 基于 [编译规则模板](templates/COMPILATION-RULES.md) 生成规则草稿，并在执行前请人确认。
- 写入或更新 `COMPILATION-RULES.md`、`COMPILATION.md`、`LEARNING-CARD.md` 和 `PITCH.md`。
- 追问人的理解、兴趣、疑问和修改意见，并把回答写入学习卡。

## 执行顺序

1. 检查 Raw 与来源，记录原文链接、作者或机构、抓取时间和 Raw 路径。
2. 根据课程模板写 `COMPILATION-RULES.md`，请人确认目标、输出和禁止事项。
3. 按确认后的规则写 `COMPILATION.md`：三句话以内的摘要、关键概念、关键实体、来源、不确定点。
4. 对照 [学习卡模板](templates/LEARNING-CARD.md) 提问：
   - 你觉得最重要的一点是什么？
   - 它和你的学习、兴趣或项目有什么关系？
   - 对文章内容，哪一点还没弄懂？
   - 对当前编译文件，哪里表达不准、来源不足或需要补充？
5. 把回答写入 `LEARNING-CARD.md`，清楚区分 Codex 编译结果与人的理解。压缩或改写人的回答时标为“按你的回答整理”；只有逐字保留时才能标为“原话”。
6. 请人回看一次来源，核对至少一条事实；收到反馈后再修订，并把待核对状态更新为实际核对位置、结论、修改说明或不确定点。
7. 根据 [Pitch 模板](templates/PITCH.md) 写出 60-90 秒草稿，请人改成自己会说的话。
8. 最后逐一检查文件存在，并报告绝对路径和人工检查结果。

## 禁止动作

- 不编造原文没有的事实、来源、作者、数据或结论。
- 不改写或覆盖 Raw 原文；需要修正时写在编译产物中。
- 不把 Codex 生成内容写成是人的原话。
- 不在 `Learn/Wiki/<主题>/` 之外写入本单元个人产物。
- 不把学习卡、Raw、Pitch 或状态摘要写入课程 repo。
- 不覆盖已有同名文件；先展示冲突并请人决定新文件名或合并方式。
- 不提交、不推送、不删除文件，不安装软件，不发外部消息。

## 输出

个人目录中必须有：

```text
<个人 Obsidian 知识库>/Learn/Wiki/<主题>/COMPILATION-RULES.md
<个人 Obsidian 知识库>/Learn/Wiki/<主题>/COMPILATION.md
<个人 Obsidian 知识库>/Learn/Wiki/<主题>/LEARNING-CARD.md
<个人 Obsidian 知识库>/Learn/Wiki/<主题>/PITCH.md
```

最终报告只列：

```text
主题目录：
Raw 路径：
四个产物路径：
来源核对项：
人工修改项：
Pitch 时长：
课程 repo：保持只读 / 需要检查
```

## 人工检查

完成前必须由人执行并回应：

1. 打开原文链接或 Raw 文件，核对学习卡中的一条事实。
2. 指出至少一处确认、修改、补充或不确定点。
3. 确认学习卡中的个人理解符合自己的意思。
4. 朗读或口述 Pitch，并删掉自己不会说的表达。

任何一项未完成，都要如实标注，不得宣布本单元完成。

## 降级路径

- Web Clipper 不可用：把原文链接和可合法保存的正文保存为 Markdown，或使用老师提供的 Raw；仍需保留来源。
- 没有自选文章：从老师提供的候选材料中选一篇，不自行虚构材料。
- 个人知识库路径未确认：停止写入并询问，不得改写到课程 repo 代替。
- 来源无法访问：换用可访问的原作者页面或老师准备的 Raw，并记录变化。
- 时间不足：保留编译规则、`COMPILATION.md`、学习卡互动、一次来源核对和 60 秒 Pitch；概念页、实体页和索引延后。
