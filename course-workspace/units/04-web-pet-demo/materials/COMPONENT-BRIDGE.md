# 学习 Workspace 与代码 repo 的连接

本 Unit 的任务说明在学习 Workspace，真正代码在独立 repo：

```text
学习 Workspace：<个人 Obsidian 知识库>/Projects/AI Agent Learning Workspace/
代码 repo：~/Projects/ai-pet-demo/
```

开始修改前，让 Codex 在代码 repo 中读取：

| 文件 | 用途 |
| --- | --- |
| `README.md` | 启动方式、目录和整体边界 |
| `AGENTS.md` | Codex 修改规则 |
| `docs/COMPONENT-MAP.md` | 外观、聊天、API 和测试分别在哪些文件 |
| `docs/API-GUIDE.md` | DeepSeek 配置、验证和排障 |
| `docs/HUMAN-AI-INTERFACE.md` | 情感、边界、不确定性和人工控制原则 |
| `public/instructions.html` | 人能看懂的改造方向与可交给 Codex 的提示词 |

学习 Workspace 不复制代码，代码 repo 不保存个人学习反思。两边通过路径、任务说明和验证摘要互相连接。
