# 从这里开始

先看同目录下的 [README.md](README.md)。

如果你要让 Agent 帮你检查，复制 [课前准备 Agent 提示词](prompts/preflight-agent-prompt.md) 给它：

```text
prompts/preflight-agent-prompt.md
```

如果你要自己手动检查，打开 [课前确认清单](materials/day-minus-1-preflight-checklist.md)：

```text
pre-lite-workspace/materials/day-minus-1-preflight-checklist.md
```

最后按 [课前确认回复模板](templates/preflight-reply-template.md) 回复老师：

```text
templates/preflight-reply-template.md
```
