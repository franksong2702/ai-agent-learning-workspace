# 从这里继续

这个 repo 已公开，不需要等待 GitHub 邀请。第一次打开后按下面顺序继续。

1. 先看 [README.md](README.md)，判断课程 workspace 现在是在 GitHub 网页中，还是已经在 Obsidian 里。
2. 如果还没有放进 Obsidian，把 [给 Codex 的 workspace 安装提示词](prompts/workspace-setup-prompt.md) 发给 Codex。
3. 安装完成后，在 Obsidian 中打开 [下一步确认清单](materials/day-minus-1-preflight-checklist.md)。
4. 最后按 [workspace 确认回复模板](templates/preflight-reply-template.md) 回复老师。
